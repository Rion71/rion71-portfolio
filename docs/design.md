# Главная страница — Light

Исходный assets/home-background.jpg сохранён без обработки. На компьютере всё изображение плавно сдвигается против мыши максимум на 2 CSS-пикселя по каждой оси, без дополнительных частиц, фильтров и шумовых слоёв. На сенсорных устройствах и при reduced motion фон статичный. Меню плавно светится при наведении за 1,8 секунды.

Логотип Light: прямые векторные контуры, равная толщина вертикалей и горизонтали. Мягкий световой слой появляется за 1,8 секунды.

Меню по центру сверху. Четыре маленьких пустых полупрозрачных квадрата со смещёнными копиями, подписи сбоку. От логотипа идут тонкие линии с низкой непрозрачностью. Разделы плавно увеличиваются при наведении за 1 секунду.

На телефоне линии скрыты, разделы расположены в две колонки. При prefers-reduced-motion увеличение отключено. Проекты редактируются через content/site.json или Pages CMS; фотографии показываются внутри разделов.
