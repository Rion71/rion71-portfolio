# RION — Visual archive

Первый прототип главной страницы. Photo / Design / Art / Custom: четыре папки в ряд на компьютере, две на телефоне. Портрет с управлением видео и кадрированием через прокрутку, плавное появление при прокрутке, hover, поддержка reduced motion и клавиатуры.

## Посмотреть
Откройте index.html в браузере: дизайн работает без установки. Для загрузки изменённого контента из JSON нужен HTTP-сервер или опубликованный сайт. Например: `python3 -m http.server 8000` в папке проекта.

## Редактирование без кода — Pages CMS
Открыть https://app.pagescms.org/ и войти через GitHub. Разрешить доступ только к этому репозиторию, выбрать main. Конфигурация `.pages.yml` уже подготовлена: тексты, фон, четыре обложки, список проектов с названием, папкой, описанием, фото и ссылкой на видео. Изменения сохраняются в content/site.json; изображения — в assets. При включённом GitHub Pages изменения появятся после публикации GitHub.

Это подготовленная интеграция, а не уже подключённый аккаунт CMS. Авторизация и проверка сохранения пока не выполнены. Редактор меняет содержание; перестройка дизайна потребует изменения шаблона.

## Границы прототипа
- Обложки — фрагменты предоставленного визуального референса, показанные через CSS; это временные иллюстрации, не реальные кейсы.
- Папки открывают диалог со списком проектов. Отдельные страницы, встроенный видеоплеер и экран Nude / Fine Art ещё не реализованы.
- Видео портрета привязано к прокрутке в обе стороны; кадр движется от лица к плечам. Использованы первые 2,8 секунды ролика, чтобы избежать позднего поворота головы. Звук удалён.
- При системной настройке уменьшения движения показывается неподвижный портрет.
- В CMS добавлено поле пути к MP4; постер меняется через поле статичного кадра. Локальное открытие index.html использует встроенные пути; изменения из CMS загружаются через HTTP.
- Контакты не публиковались: публичные контактные данные не были предоставлены для сайта.
- Нет платных сервисов, аналитики, токенов и сторонних библиотек.
