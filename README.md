# RION — Visual artist

Тёмная главная с пользовательским фотографическим фоном, готической монограммой и четырьмя разделами: Photo, Design, Art, Custom. Лёгкий параллакс мыши на компьютере, усиление свечения логотипа при наведении. На телефоне — статичный фон и два раздела в ряд.

## Открыть прототип
GitHub → Code → Download ZIP. Распакуйте папку и откройте `index.html` в браузере. Фон, монограмма, обложки и движение мыши работают без сервера.

Для загрузки проектов и изменённых настроек из `content/site.json` используйте локальный сервер: `python3 -m http.server 8000`, затем http://localhost:8000. При прямом открытии файла используются встроенные демонстрационные данные.

## Редактирование
В `.pages.yml` подготовлены поля Pages CMS: фон, логотип, обложки, описание автора и проекты. https://app.pagescms.org/ → вход через GitHub → Rion71/rion71-portfolio. Авторизация пользователя и сохранение из CMS пока не проверены. Изменение содержимого не перестраивает дизайн.

## Материалы
См. `docs/design.md`. `assets/home-background.jpg` — неизменённый оригинал «ДЛЯ САЙТА.jpg». Демонстрационные обложки взяты из визуального концепта, это не реальные проекты. Старая видеоверсия сохранена в истории Git и прежних медиафайлах.

## Проверка и статус
JavaScript проверен на синтаксис; ресурсы и целостность исходного фона проверены. Визуальная проверка в браузере среды недоступна. Сайт не публиковался, GitHub Pages и платные сервисы не подключались. Публикация — после отдельного согласия владельца.
